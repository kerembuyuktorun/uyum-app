# Uyum

**Compliance that keeps pace with the counter.**

Uyum is a web-based SaaS platform for jewelers that combines AML/KYC compliance, customer onboarding, payment tracking, e-Invoice / e-Archive workflows, document archiving, and audit-ready reporting — built for store owners, employees, accountants, and audit prep, on desktop, tablet, and checkout screens.

## Core modules (v1)

| Module | Purpose |
|---|---|
| Dashboard | Attention queue & compliance health |
| Customers | Onboarding & customer hub |
| Compliance | AML/KYC cases & risk review |
| Payments | Payment capture & reconciliation |
| Invoicing | e-Invoice / e-Archive pipeline |
| Documents | Linked archive & retention |
| Reports | Audit packs & operational reports |
| Settings | Org, roles, integrations |

## Primary user flow

```
Onboard customer → AML/KYC check → Record payment → e-Invoice / e-Archive → Archive docs → Audit pack
```
