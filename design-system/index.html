Layout & responsive rules

Desktop (≥1120px): 240px navy sidebar, 12-column dashboard, full tables.

Tablet (768–1119px): icon rail sidebar, stacked dashboard columns, horizontal table scroll with sticky first column.

Mobile (<768px): drawer navigation, stacked panels, full-width primary actions, modal bottom sheet.

Touch targets for sales actions stay at least 40–44px. Motion is limited to sidebar, modal enter, and status tint updates.
